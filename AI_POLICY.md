# AI use in VectisDB contributions

AI tools may help contributors explore an idea, explain unfamiliar code, or review a patch. The person
submitting a change remains responsible for its behavior, license, security, and test results.

Review generated code and prose before submitting them. Check that code fits the project, that cited
sources exist, and that copied material is compatible with the repository's license. Do not submit
output you cannot explain or maintain.

Do not send secrets, private user data, or non-public vulnerability reports to an AI service. If an AI
tool produced a substantial part of a contribution, mention that in the pull request so reviewers have
the context they need. Routine autocomplete does not need a separate note.
