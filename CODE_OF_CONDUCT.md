# Code of Conduct

VectisDB discussions should stay useful to people working on the project. Be direct about technical
problems, and respectful toward the people discussing them. Critique code and ideas without making it
personal.

Harassment, slurs, threats, unwanted sexual attention, publishing someone's private information, and
repeated personal attacks are not acceptable here. The same expectations apply in issues, pull requests,
discussions, and other spaces used for VectisDB work.

Project maintainers may remove comments, close a discussion, or restrict participation when needed.
They will consider the impact and pattern of the behavior when deciding what to do.

To report a concern, contact the maintainers privately through the contact options on the
[Vectorphy GitHub profile](https://github.com/Vectorphy). Please do not post sensitive details in a
public issue.

These expectations follow the principles in the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
